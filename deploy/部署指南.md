# D全屋家居 部署指南

> 版本：v1.0 ｜ 日期：2026-08-19 ｜ 依据：《开发技术文档 v1.2》§7 部署 + PRD D9
> 技术栈：后端 FastAPI + SQLite（单文件，零外部依赖）；前台/后台 React 静态构建；Nginx 统一托管

---

## 1. 架构与端口

```
浏览器(访客/管理员)
   │ HTTPS
   ▼
Nginx (:80/:443)  ──静态──▶ frontend/dist（前台官网）
   │  /admin  ──静态──▶ backend/dist（后台管理）
   │  /api    ──反代──▶ uvicorn (127.0.0.1:8000)  ──▶ SQLite app.db
   │  /uploads──静态──▶ api/uploads（图片直出，ADR-003）
```

## 2. 开发环境（本地三端启动）

前置：Python 3.13 + Node 22（或更高）。

```bash
# 后端（首次会自动建表+种子+初始管理员）
cd api
python -m venv .venv                     # 首次
.venv\Scripts\activate                   # Windows；Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt          # 首次
python -m app.init_db                    # 建表+种子（幂等）
uvicorn app.main:app --reload --port 8000

# 前台官网（另开终端）
cd frontend
npm install                              # 首次
npm run dev                              # http://localhost:5173（/api 已代理到 8000）

# 后台管理（另开终端）
cd backend
npm install                              # 首次
npm run dev                              # http://localhost:5174（/api 已代理到 8000）
```

> 或使用 `bash deploy/start-dev.sh`（Git Bash）一键启动后端。
> 初始账号：`admin`，密码见 `api/.env` 的 `INIT_ADMIN_PASS`；首次登录强制改密。

## 3. 生产部署（Linux + Nginx + systemd，推荐）

### 3.1 目录规划
```
/opt/d-home/
├─ api/                # Python 后端（FastAPI，含 .env、.venv、uploads/）
├─ backend/            # 后台管理系统构建产物（React + Ant Design）
├─ frontend/           # 前台官网构建产物（React + Tailwind）
└─ deploy/             # 本目录配置
```

### 3.2 构建前端
```bash
cd frontend && npm ci && npm run build    # 产出 frontend/dist
cd ../backend && npm ci && npm run build  # 产出 backend/dist（后台管理）
```

### 3.3 后端部署
```bash
cd /opt/d-home/api
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
# 配置环境（关键！生产必须修改）：
#   JWT_SECRET      → 强随机串（如 openssl rand -hex 32）
#   INIT_ADMIN_USER/PASS → 部署方指定初始管理员（上线后首次登录强改密）
.venv/bin/python -m app.init_db           # 建表 + 种子

# systemd 守护（可选）
sudo cp /opt/d-home/deploy/d-home-backend.service /etc/systemd/system/
sudo systemctl daemon-reload && sudo systemctl enable --now d-home-backend
```

### 3.4 Nginx 配置
```bash
sudo cp /opt/d-home/deploy/nginx.conf /etc/nginx/conf.d/d-home.conf
# 编辑 nginx.conf：替换 server_name 为正式域名；如启用 HTTPS 参考文件内注释（Let's Encrypt）
sudo nginx -t && sudo systemctl reload nginx
```

### 3.5 验证
```bash
curl http://127.0.0.1:8000/api/health     # 后端
curl -I http://localhost/                  # 前台首页
curl -I http://localhost/admin             # 后台
```

## 4. Docker 部署（可选）

```bash
docker build -f deploy/Dockerfile -t d-home-backend .
docker run -d --name d-home-backend -p 8000:8000 -v d-home-data:/data d-home-backend
# Nginx 仍由宿主机托管静态与反代（配置同上，proxy_pass 指向容器映射端口）
```

## 5. 上线前核对清单（D9：正式域名/证书/服务器由用户上线前提供）

- [ ] `api/.env` 已配置强随机 `JWT_SECRET`（**禁止使用默认值**）
- [ ] 初始管理员密码已设置（`INIT_ADMIN_PASS`），上线后首次登录强制改密
- [ ] 正式域名已解析到服务器，HTTPS 证书就绪（Let's Encrypt / 商业证书）
- [ ] `nginx.conf` 的 `server_name` 已替换为正式域名
- [ ] 高德 Key（JS API）已申请并配置：`frontend/.env.local` 写入 `VITE_AMAP_KEY`，Key 安全域名加入正式域名
- [ ] 真实内容素材已通过后台录入（产品/案例/新闻/Banner/门店/关于我们/联系信息）
- [ ] 询盘中心核对：历史测试询盘已清理（无效标记或数据库清理）
- [ ] 后台/前台生产构建为最新（`npm run build` 后重启 Nginx 无需）
- [ ] 验收走查：对照《D全屋家居-验收清单.md》逐条确认

## 6. 数据与备份

- 数据库：`api/app.db`（单文件）；备份 = 复制该文件 + `api/uploads/` 目录
- 建议每日 cron 备份：`tar -czf /backup/d-home-$(date +%F).tgz /opt/d-home/api/app.db /opt/d-home/api/uploads`
- 迁移 PostgreSQL：见《数据库设计文档》§9（仅改 `DATABASE_URL` + 类型适配，ORM 可复用）
